# Security policy

This service exposes public, read-only reference data. It must never accept instructions to write to a production identity graph, promote evidence, edit policies, or mint authorization records.

Please report security issues privately to the maintainer using the contact details on <https://danielberanek.cz/>. Do not publish exploit details or credentials in public issues.

Do not submit API tokens, private evidence, graph records, personal data, or sensitive application context to the public MCP service. Tool inputs are intended for labels and short domain-context descriptors only.
